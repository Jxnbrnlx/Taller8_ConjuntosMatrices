# Taller 8: Matrices y conjuntos en Python

Este repositorio contiene los dos ejercicios del Taller 8 de Lógica de Programación.

## Contenido

- Ejercicio 1: Análisis de una matriz de ventas.
- Ejercicio 2: Análisis de estudiantes inscritos en dos cursos utilizando conjuntos.

## Temas trabajados

- Matrices y listas anidadas.
- Ciclos for y acumuladores.
- Conjuntos (set).
- Unión, intersección y diferencia.
- Modificación y consulta de información.
